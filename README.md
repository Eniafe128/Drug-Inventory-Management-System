# Drug-Inventory-Management-System
Drug inventory management system built with basic Python concepts

## Project Overview
This project was developed as Case Study Project #2 for the Python Study Group. It simulates a simple drug inventory management system for HealthyLife Pharmacy using only basic Python concepts.

## Project Goal
To build a drug inventory checker that:
- Calculates remaining stock
- Computes daily sales revenue
- Updates inventory
- Checks restocking requirements
- Verifies expiry status
- Determines if drugs are safe to sell
- Checks discount eligibility

## Dataset Description
This project uses manually created sample data provided in the case study.

Example:

- Drug Name: Paracetamol
- Price: ₦850
- Quantity in Stock: 250
- Quantity Sold Today: 65
- Minimum Stock: 100
- Expired: False

## Tools Used
- Jupyter Notebook

## Concepts Used
- Variables
- Data Types
- Assignment Operators
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- f-Strings
- Multiline Strings

## Steps Followed
1. Created variables for drug information.
2. Calculated remaining stock.
3. Calculated daily sales revenue.
4. Updated stock using assignment operators.
5. Checked if restocking was required.
6. Verified expiry status.
7. Determined whether the drug was safe to sell.
8. Checked discount eligibility.
9. Displayed a professional inventory report.

## Results
The program successfully:
- Updated inventory correctly.
- Calculated revenue.
- Determined restocking status.
- Verified drug safety.
- Generated a readable inventory report.
